# ADR-0001 — Aplicação local isolada por instalação

Decisão técnica dentro do G0 aprovado: Next.js 16.4.6/React, TypeScript, PostgreSQL 17, Better Auth 1.7.21, pdf-lib; sem API Python de produto. Python/Pydantic no harness. Node 22 local necessário porque Kysely exige >=22. Lockfile fixa dependências; versões consultadas no registry em 2026-11-12. Referências oficiais: https://nextjs.org/docs/app/getting-started/installation e https://better-auth.com/docs/installation e https://better-auth.com/docs/adapters/postgresql .

Uma empresa por banco/instalação. Licença + implantação; faturamento de assinatura e multi-tenancy fora. Next server aplica autorização e transações pg; revisions e audit_events possuem triggers append-only. Estes triggers não protegem contra um administrador do PostgreSQL. PDF preserva snapshot e não busca recursos externos.

G0 aprovado na conversa em 2026-11-12. Host público, retenção de dados reais e licença comercial final continuam decisões de release; não impedem demo sintética. Conformidade TSF de operação paga/24h não é reivindicada: adapter de modelos e scheduler não habilitados. Runtime atual é desenvolvimento supervisionado com checks reproduzíveis, snapshots de conteúdo, envelopes e ledger simulado.
